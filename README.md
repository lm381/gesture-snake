# 🐍 AI 手势贪吃蛇 (Gesture Snake)

基于 MediaPipe 运行的纯前端 AI 手势贪吃蛇游戏，打开浏览器即可游玩，无需下载安装任何软件或插件。

🎮 **[点击直接在线试玩](https://lm381.github.io/gesture-snake/)**

---

## ✨ 项目特色
- **AI 隔空识别**：实时追踪手部与食指位置，跟随指尖灵活转向。
- **纯前端零门槛**：单文件 HTML/JS 驱动，通过 GitHub Pages 免费部署。
- **全平台多模式兼容**：
  - 摄像头模式：通过手掌/食指隔空遥控。
  - 触控/鼠标模式：直接在屏幕滑动或移动鼠标操控。
- **弱网容错机制**：AI 模型加载异常时自动切换为触控操作，杜绝卡屏。

## 🕹️ 游玩说明
1. 打开网页，点击 **“启动摄像头开始游戏”**。
2. 在浏览器弹窗中点击 **“允许”** 开启相机权限。
3. 将手掌正面朝向摄像头（保持约 40~60 厘米距离），挥动手掌或食指即可引导贪吃蛇吞食红苹果！
